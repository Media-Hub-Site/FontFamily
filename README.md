# ✒️ MediaHub — FontFamily Atelier v1.0.0

Estudio editorial de composición tipográfica Unicode, caracteres invisibles, símbolos especiales, marcos estéticos y emojis para el ecosistema **MediaHub**.

## ✨ Características Principales

- **Mesa de Composición en Vivo ("El Telar Tipográfico")**: Combina múltiples tipografías Unicode (ej. `𝔉𝔯𝔞𝔨𝔱𝔲𝔯` + `𝓢𝓬𝓻𝓲𝓹𝓽`), caracteres invisibles, símbolos raros y emojis dentro de una misma caja de texto antes de copiar el resultado final.
- **Modo Teclado Tipográfico en Tiempo Real**: Activa cualquiera de las **30+ fuentes Unicode** como fuente de teclado y escribe directamente con ella en vivo, con soporte completo para acentos del español y la letra `ñ`.
- **Laboratorio de Caracteres Invisibles + Visor Rayos-X (`👁`)**: Inserta o copia caracteres invisibles (`U+3164` Hangul Filler, `U+2800` Vacío Braille para Instagram, `U+200B` Ancho Cero, etc.) y visualiza su posición exacta con el modo Rayos-X.
- **Bóveda de 350+ Símbolos Especiales, Marcos Envolventes, Kaomojis & Emojis**: Inserción en 1 clic directamente en la posición de tu cursor.
- **3 Temas Estéticos Atelier**: *📜 Papel Editorial* (por defecto), *🍷 Atelier Nocturno* y *🍵 Cyber Matcha*.
